- CTR-1 game-specific work blocked by authorization/provenance; generic contracts can proceed independently.

- Subtask C uses a fixed two-player, four-slot model and an immutable synthetic payment program. No serialized effect trace, integrity/authentication, external rules/program digest, explicit chance in this fixture, or production replay.
